# 共用タブレットを専用端末にする手順

研究室や事務室に置いて「このアプリしか使えない端末」にするための設定。

---

## 買う前に確認すること

### カードリーダーの種類（重要）

**USB HID（キーボードエミュレーション）方式**のものを買うこと。

| 方式 | Android での扱い | 判断 |
| --- | --- | --- |
| **USB HID** | カード番号を「キーボード入力」として送ってくる。OS が標準で扱えるので、アプリ側は文字を受け取るだけ | ◎ これを買う |
| PaSoRi RC-S380 など | 専用ドライバと独自プロトコルが必要。Android 向けの公式 SDK が無い | ✗ 避ける |

商品説明に「USB HID」「キーボードエミュレーション」「キーボードとして認識」
といった記載があるものを選ぶ。「PC 用ソフトが必要」と書かれているものは避ける。

接続には USB OTG 対応のタブレットと、必要なら OTG 変換アダプタが要る。

### タブレット

- Android 8.0 以降（このアプリの下限）
- USB OTG 対応
- 内蔵 NFC は不要（外付けリーダーを使うため）

---

## 1. 端末を初期化する

**Device Owner は「アカウントが 1 つも登録されていない端末」にしか設定できない。**
新品でも、初回設定で Google アカウントを追加してしまうと設定できなくなる。

1. 設定 → システム → リセット → 全データを消去
2. 再起動後の初期設定で、**Google アカウントの追加をすべてスキップ**
3. Wi-Fi だけ繋いでおく

---

## 2. USB デバッグを有効にする

1. 設定 → デバイス情報 → ビルド番号を 7 回タップ
2. 設定 → システム → 開発者向けオプション → USB デバッグ を ON

---

## 3. アプリを入れて Device Owner に設定する

PC に USB で繋いで、次を実行する。

```powershell
adb install -r app-debug.apk
adb shell dpm set-device-owner jp.naramed.campusplanpoc.debug/jp.naramed.campusplanpoc.kiosk.PortalDeviceAdminReceiver
```

`Success` と出れば設定完了。

うまくいかない場合:

| エラー | 原因 |
| --- | --- |
| `Not allowed to set the device owner because there are already accounts` | アカウントが残っている。初期化からやり直す |
| `device owner is already set` | 既に別アプリが設定されている。初期化からやり直す |
| `Unknown admin` | パッケージ名が違う。release ビルドなら `.debug` を外す |

---

## 4. アプリ側で固定する

1. アプリを起動してログインする
2. 学生証 → この端末の設定
3. **管理者PIN を先に設定する**（これを忘れると解除できなくなる）
4. 「このアプリだけ使える状態にする」を ON

これで、ホームキー・戻る・履歴が効かなくなり、再起動してもこのアプリが立ち上がる。

---

## 解除するには

アプリ内から:

1. 学生証 → この端末の設定
2. 「このアプリだけ使える状態にする」を OFF → 管理者PIN を入力

PIN を忘れた場合は、PC から:

```powershell
adb shell dpm remove-active-admin jp.naramed.campusplanpoc.debug/jp.naramed.campusplanpoc.kiosk.PortalDeviceAdminReceiver
```

それでも駄目なら端末を初期化する。

---

## 運用上の注意

- **管理者PIN を設定してから固定すること。** 固定を先にすると、解除できずに
  初期化するはめになる。
- Device Owner を設定した端末は、解除しない限り他の管理アプリを入れられない。
- このアプリは「閉じたら自動ログアウト」が既定で有効。共用端末ではそのままにしておく。
- 登録したログイン情報は端末内で暗号化して保管される。端末を手放すときは、
  学生証画面から登録をすべて削除するか、端末を初期化すること。
